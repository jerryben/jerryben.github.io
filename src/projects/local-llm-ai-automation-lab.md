This lab is where I run open-source models locally and wire them into practical, repeatable workflows instead of one-off experiments.

## What it covers

- Running and comparing open-source models locally with **Ollama**
- Routing requests across providers and models with **LiteLLM**
- Building agentic workflows in **n8n** — from a Telegram trigger to a fully summarized report
- Evaluating model output quality for real tasks, not just benchmarks

## Why local-first

Running models locally keeps iteration fast and cheap, and forces me to understand what's actually happening in a request/response cycle instead of treating an API as a black box. That understanding carries directly into how I design AI features for the web — including the chat assistant on this site.
